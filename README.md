# Dictionary Application using Hash Tables

## Aim
To implement a dictionary application using hash tables
to store and retrieve words and their meanings efficiently.

## Description
This project implements a simple dictionary using a
hash table. Each word is stored along with its meaning.
A hash function calculates the index where the word
will be stored.

Separate chaining is used to resolve collisions when
multiple words map to the same index.

## Features
- Add a new word and its meaning
- Search for a word
- Update an existing word's meaning
- Delete a word
- Display all words and meanings
- Handle collisions using separate chaining

## Data Structure Used
Hash Table with Separate Chaining

## Programming Language
Python 3

## Operations
1. Insert
2. Search
3. Delete
4. Display
5. Exit

## Conclusion
The dictionary application demonstrates the use of
hash tables for storing and retrieving data efficiently.
Separate chaining helps manage collisions when two
or more words have the same hash index.
